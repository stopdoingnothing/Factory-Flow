# HR Quick Reference — Checkpoint Leave Management System

**Designed to be scanned in under 2 minutes. Keep this tab open or print and post by your desk.**

---

## 1. Morning Checklist

Do this when you start your day:

1. **Check your inbox** — Look for leave requests waiting in `Queue`. If red badge shows on leave requests, prioritize those first.
2. **Review yesterday's notifications** — Any bounced approvals or manager escalations? Address immediately.
3. **Check for new grievances** — Badge on Grievances nav. Flag urgent confidential matters.
4. **Scan the Dashboard** — Pending approval count, overdue requests, staff on leave today.
5. **Update any manual attendance** — If kiosk failed to record, fix attendance records before 9 AM.

## 2. Common Tasks

| Task | Steps |
|------|-------|
| **Approve a leave request** | Open Queue → find request → Review manager recommendation → Click Approve → Done |
| **Reject a leave request** | Queue → find request → Click Reject → Optionally add comment to staff → Done |
| **Request medical certificate** | Queue → find sick leave → Click "Request Medical Cert" → Certificate marked due |
| **Add a new employee** | Personnel → Create Employee → Fill required fields (Name, ID, email, role) → Password auto-sent → Done |
| **Adjust leave balance manually** | Leave Balances → Select employee → Select leave type → Click pencil → Adjust reason → Update |
| **Register employee faces** | Face Registration → Select employee → Capture 2–3 angles → Save → Test on kiosk |
| **Create public holiday** | Leave Rules → Public Holidays → Add Date → Name → Apply → Auto-blocks leave approvals |
| **Check who's on leave today** | Dashboard → **On Leave Today** card → See list with leave type |
| **Export attendance for payroll** | Attendance → Select date range → Click Export → CSV downloads → Save for payroll |
| **View audit log for an employee** | Personnel → Select employee → Scroll to Activity → All changes logged with timestamp & user |

## 3. Leave Status Guide

| Leave Status | What It Means | Where It Sits | Who Acts Next |
|--------------|---------------|---------------|---------------|
| **Draft** | Employee started but didn't submit | Employee inbox | Employee (must submit to manager) |
| **Submitted** | Waiting for manager recommendation | Manager Queue | Manager (approves or declines) |
| **Recommended** | Manager approved, now waiting for HR | Your Queue | **You** (approve or reject) |
| **Approved** | HR approved, leave is locked | Employee calendar | None (leave is granted) |
| **Rejected** | HR rejected (employee notified) | Employee history | Employee (can reapply if eligible) |
| **Cancelled** | Employee or admin cancelled approved leave | Employee history | None (leave refunded to balance) |
| **Escalated** | Manager didn't respond in 3 days | Escalation reminder sent to manager | Manager (urgent response needed) |
| **Awaiting Cert** | Medical cert requested for sick leave | Employee inbox | Employee (must upload cert, or leave voids) |

## 4. Key Rules to Remember

These catch people out — memorize them:

1. **Sick leave requires medical cert after 2 consecutive days.** If employee doesn't upload by deadline, leave request voids automatically.

2. **Half-day leave counts as 0.5 days, not full day.** If employee takes morning off, balance deducts 0.5 (not 1).

3. **Annual leave accrues monthly, not upfront.** New employees don't get full year's balance on day 1. Check their cycle start date.

4. **You cannot approve your own leave.** The system blocks self-approval. Manager recommends, HR approves.

5. **Carry-over unused leave expires 3 months after cycle end.** Mark a calendar reminder for expiry dates to avoid losing days.

6. **FRL (Family Responsibility Leave) is 3 days per year, not per request.** Once employee uses 3 days total, no more FRL can be approved until next cycle.

7. **Manager can only see and approve their direct reports' leave.** Create correct supervisor hierarchy or manager won't see anything to action.

8. **Public holidays block leave approval.** If the date falls on a public holiday, leave request auto-rejects (employee cannot take leave on a public holiday).

9. **Unpaid leave requires 7-day notice in advance.** If employee requests unpaid with fewer than 7 days notice, system flags it — check your escalations.

10. **Attendance records must be corrected by 9 AM.** Any manual edits after 9 AM may affect payroll. Post a morning cutoff in your team chat.

## 5. Email Notifications Reference

| Email | Sent To | What Triggers It | Your Action |
|-------|---------|-----------------|-------------|
| **Leave Request Submitted** | Manager | Employee submitted leave (waiting for recommendation) | Manager must review in Queue |
| **Manager Recommendation Given** | You (HR) | Manager approved/rejected in their queue | Check Queue; approve or reject |
| **Leave Approved** | Employee | You approved in HR Queue | None (employee sees on calendar) |
| **Leave Rejected** | Employee | You rejected in HR Queue | None (employee notified, can reapply) |
| **Medical Certificate Requested** | Employee | Sick leave requires cert (2+ days) | Employee must upload cert |
| **Cert Deadline Approaching** | Employee | 24 hours before cert deadline | Remind employee if they haven't uploaded |
| **Medical Certificate Overdue** | You (HR) | Employee missed cert deadline | Void the leave request manually |
| **Manager Escalation Alert** | Manager | Manager took >3 days to respond | Manager reminded to action request |
| **Unpaid Leave Notice** | You (HR) | Employee requested unpaid with <7 days notice | Check escalation flag; may need follow-up |
| **Leave Cancelled** | Manager + Employee | Leave was cancelled (approved → cancelled) | Balance auto-refunded to employee |
| **Attendance Manual Edit** | Your email | Someone edited an attendance record | Review audit log to confirm change |
| **Grievance Filed** | You (HR) | New grievance submitted | Review immediately; flag if confidential |
| **Grievance Status Updated** | Employee | You updated grievance status | Employee kept in the loop |
| **Face Registration Needed** | Employee | Face not registered or failed kiosk | Employee needs to visit registration |
| **System Backup Complete** | You (Admin) | Nightly backup completed (6-hour interval) | No action (confirmation only) |

## Quick Escalation Contacts

- **System down or container issue** → Admin (check troubleshooting guide)
- **Balance calculation looks wrong** → Admin (may need balance reset or accrual debug)
- **Face recognition failing at kiosk** → Check employee face registration; re-register if needed
- **Email not received** → Check spam; may be Postmark issue (admin escalates to support)
- **Leave Rules questions** → See Admin Reference Manual section 10 for BCEA rules and tiers
- **Policy question not in these docs** → Check HR User Guide section 11 (Common Scenarios)
