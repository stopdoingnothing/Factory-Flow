# Checkpoint Training Documentation

Three guides to help you use the AECE Checkpoint leave management system.

---

## Which Guide Do I Need?

### 🆕 **New HR Hire?** → [HR User Guide](hr-user-guide.md)

Start here on your first day. This is your complete onboarding manual covering every routine task:
- How to log in and navigate the dashboard
- Step-by-step instructions for approving leave, managing employees, and handling grievances
- How to adjust leave balances, register faces, and export reports
- Common scenarios and edge cases you'll encounter
- Glossary and escalation contacts

**~45 pages | Read over your first week | Return to sections as needed**

---

### ⚙️ **System Administrator?** → [Admin Reference Manual](admin-reference-manual.md)

Your complete technical reference for every setting, capability, and configuration:
- Initial setup checklist and system architecture
- Field-by-field documentation of every setting (General, Branding, Permissions, etc.)
- Leave calculation formulas and balance engine deep dive
- Database backup/restore procedures
- Email notification matrix and API reference
- Troubleshooting guide for common issues

**~75 pages | Use as a reference alongside your daily work | Search for specific topics**

---

### ⚡ **Quick Lookup During Your Shift?** → [HR Quick Reference](hr-quick-reference.md)

One-page scannable cheat sheet for trained HR users. Keep this open in a tab or printed by your desk:
- Morning checklist (5 items, 1 minute)
- Common tasks lookup table
- Leave status guide (what each status means)
- 10 key rules that catch people out
- Email notifications quick reference
- Escalation contacts

**~2 pages | Scan in under 2 minutes | Print if you prefer**

---

## How to Use These Guides

1. **New to the system?** Start with the **HR User Guide**. Read sections in order or jump to what you need.

2. **Implementing a system change?** Use the **Admin Reference Manual**. Search for the feature, then follow the step-by-step instructions.

3. **In a hurry?** Use the **HR Quick Reference**. Tables, checklists, and key rules only — no prose.

4. **Still stuck?** Check the escalation contacts at the bottom of the Quick Reference, or revisit the full guide for that topic.

## Document Format & Features

All documents use:
- **Table of Contents with anchor links** (click to jump to sections)
- **Numbered procedures** for every task (easy to follow)
- **Callout blocks** for tips (`> **Note:**`), warnings (`> **Warning:**`), and admin-only sections
- **Reference tables** for quick lookup
- **Glossary** in the HR User Guide for technical terms
